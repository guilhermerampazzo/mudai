Catálogo dinâmico, painel de plantas e IA em produção

Servidor:
- Catálogo de plantas em JSON persistido no volume (semeado com as 200 do app)
- GET /api/v1/catalogo serve o catálogo; o app sincroniza e cacheia localmente
- Painel /admin no próprio app web: cadastrar, editar e remover plantas com
  upload de foto, protegido por ADMIN_TOKEN
- Identificação por IA agora grava a planta no catálogo (dedup por nome
  científico), servindo de cache e enriquecendo a base
- Chat do Hachimi recebe o catálogo como contexto (cita faixas reais de lux)
- Cache de identificação persistido em disco
- Prisma e Postgres/Redis removidos: nada no código usava (stack mais leve
  para a VPS)

Infra:
- Compose reduzido a api + web + gateway, uma porta externa (10233)
- Gateway passa / para o container web (antes servia um nginx vazio)
- Dockerfiles corrigidos para o contexto do build
- Seed do catálogo incluído no build da API

App:
- Consome o catálogo do servidor com fallback para o catálogo embutido
- Fotos resolvidas por origem (empacotadas ou enviadas ao servidor)
- Aponta para https://mudai.codermaster.com.br em produção
